# READMEv1.2 - MOEX APP2+ / docs2 source of truth

Файл: `docs2/READMEv1.2.md`

Эта версия дополняет `READMEv1.1.md` и исправляет ещё одну проблему:
- в `docs2` должен быть не только новый входной контур, но и **полный перенос правил** из старого `docs`.

## 0. Что читать первым

При новом входе / миграции:
1. `docs2/READMEv1.2.md`
2. `docs2/DOC_INDEX_v1.2.md`
3. `docs2/policies/PROJECT_RULES_v1.0.md`
4. `docs2/operations/MIGRATION_CONTEXT_v1.2.md`
5. `docs2/CONTRACTv1.2.md`
6. `docs2/model_plan_v1.1.md`

## 1. Текущая рамка проекта

- core - главный контур развития;
- legacy - только reference / sanity-check;
- песочница - обязательный этап пути к online, но не финальная цель;
- финальная цель проекта - исследовательски честная offline/online торговая система;
- docs2 - новый source of truth для миграции, правил и дальнейшего планирования.

## 2. Правила теперь не потеряны

Полный набор правил из старых `docs/READMEv*` и договорённостей перенесён в:
- `docs2/policies/PROJECT_RULES_v1.0.md`

Новые чаты и новые итерации обязаны опираться на этот файл, а не только на краткие вводные.

## 3. Что остаётся обязательным

- изменения файлов только новыми версиями
- дополнение, а не обнуление документации
- сначала чтение правил и migration context
- только потом анализ кода и предложения по roadmap / патчам

## 4. Сохранённая история из предыдущей версии

Для сохранения хронологии и смысла сохраняется вся история из `READMEv1.1.md`, включая приложенные `READMEv4.9` и `READMEv4.10`.
