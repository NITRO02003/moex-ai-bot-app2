# LLM_WORKFLOW_v1.3 - роли ChatGPT, Qwen и agent_hands

## 1. Общая рамка

Этот документ дополняет `PROJECT_RULES_v1.1.md` и не заменяет его.
Если правила и workflow пересекаются, источник истины - полный свод правил проекта.

## 2. Что обязан сделать новый чат

1. Прочитать:
   - `docs2/READMEv1.3.md`
   - `docs2/DOC_INDEX_v1.3.md`
   - `docs2/policies/PROJECT_RULES_v1.1.md`
   - `docs2/operations/MIGRATION_CONTEXT_v1.3.md`
   - `docs2/CONTRACTv1.3.md`
   - `docs2/model_plan_v1.2.md`
2. Подтвердить понимание правил.
3. Кратко восстановить стадию проекта и риски.
4. Только потом переходить к анализу `app2` и предложениям.

## 3. ChatGPT

Роли:
- анализ;
- roadmap;
- контракты;
- патчи;
- миграционный контур.

Режим работы:
- по умолчанию режим критика;
- без лести и без автосогласия;
- сначала фактическое состояние `app2`, потом старые промежуточные описания;
- в режиме агента - только короткие итерации по 1-2 действия;
- каждый патч завершает self-check и отдается архивом только с измененными файлами.

## 4. Qwen

- локальный reviewer / debugger;
- внешний аналитик;
- не source of truth.

## 5. agent_hands

- read-only bridge;
- не обходит patch discipline;
- не может считаться автором изменений.

## 6. Режим агента для этапа 1.1

Агент делает только следующее:
1. проверяет фактические файлы `app2`;
2. выбирает один ближайший микро-шаг из `model_plan_v1.2.md`;
3. вносит минимальный патч;
4. делает self-check;
5. возвращает архив измененных файлов;
6. коротко фиксирует риск, остатки долга и следующий возможный шаг.

Что агент не делает:
- не расползается в широкий рефакторинг без закрытия текущего шага;
- не придумывает проверки, которых не было;
- не скрывает нехватку файлов, данных или окружения.

## 7. Что нельзя делать

- сокращать правила до 3-4 пунктов, если проект уже имеет более длинный набор договоренностей;
- считать новый миграционный пакет полным без переноса старых правил;
- предлагать патчи без чтения docs2 source of truth;
- возвращаться к планированию через `legacy` как обязательный comparative baseline;
- отвечать в режиме сглаживания вместо режима критика.
