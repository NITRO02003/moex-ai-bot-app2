# LLM_WORKFLOW_v1.1 - роли ChatGPT, Qwen и agent_hands

## 1. Обязательные правила

1. Если документ меняется, версия файла должна меняться.
2. Исходное содержание документов должно дополняться, а не переписываться с нуля.
3. Исключения допускаются только после согласования с пользователем.
4. При миграции чата новый чат обязан сначала читать docs2 и правила/договорённости между нами.
5. Любые предложения внешних моделей сначала фиксируются в docs и только потом становятся задачами на патч.

## 2. ChatGPT
- анализ
- архитектура
- roadmap
- патчи
- фиксация договорённостей в docs

## 3. Qwen
- локальный reviewer / debugger
- источник гипотез
- не source of truth

## 4. agent_hands
- read-only bridge к локальной модели
- не должен записывать изменения в проект
- не должен обходить патч-дисциплину

## 5. Что обязательно помнить новому чату
- сначала прочитать docs2
- потом анализировать app2
- только после этого предлагать изменения
