# LLM_WORKFLOW_v1.0 - роли ChatGPT, Qwen и agent_hands

## 0. Назначение

Этот документ фиксирует:
- кто какую роль играет;
- как внешние предложения попадают в проект;
- как не допустить скрытого изменения системы;
- как использовать внешнюю критику без потери контроля.

## 1. ChatGPT

Роль:
- архитектурный анализ;
- roadmap;
- contracts / docs;
- патчи по согласованному ТЗ;
- критическая ревизия решений.

Обязанности:
- опираться на source-of-truth docs;
- не терять смысл уже зафиксированных решений;
- явно говорить, если файл отсутствует или версия сомнительна.

Ограничения:
- не меняет контракт молча;
- не считается источником истины без фиксации в docs;
- не может обходить patch discipline.

## 2. Qwen

Роль:
- локальный debugger;
- внешний reviewer;
- генератор гипотез и контраргументов;
- быстрый анализ файлов и трейсов.

Ограничения:
- не является source of truth;
- не утверждает архитектурные решения без фиксации в docs;
- его выводы рассматриваются как вход для обсуждения, а не как автоматическое решение.

## 3. agent_hands

Роль:
- bridge к локальной модели;
- вспомогательный read-only инструмент анализа.

Текущий режим:
- read-only.

Разрешено:
- LIST_DIR
- READ_FILE
- сбор наблюдений

Запрещено:
- WRITE_FILE
- скрытые правки проекта
- обход патч-дисциплины
- изменение docs без отдельного решения

## 4. Внешние аналитики

Проект допускает привлечение сторонних наблюдателей без глубокого погружения в детали.
Их роль:
- дать независимую критику;
- указать на blind spots;
- подсветить research / engineering risks.

Правило:
- если мы согласны с замечанием внешнего аналитика, оно включается в план разработки;
- приоритет определяется текущей стадией проекта.

## 5. Как идеи попадают в проект

1. внешняя модель / аналитик / LLM даёт идею или критику;
2. идея обсуждается;
3. если принята, фиксируется в docs2;
4. затем только идёт патч;
5. при необходимости обновляется migration context.

## 6. Что важно при миграции чата

Новый чат должен читать:
- `READMEv1.0`
- `DOC_INDEX_v1.0`
- `ARCHITECTURE_BLUEPRINT_v1.0`
- `CONTRACTv1.0`
- `model_plan_v1.0`
- `RESEARCH_POLICY_v1.0`
- `MIGRATION_CONTEXT_v1.0`

Это обязательный минимальный контур, чтобы ChatGPT и новый чат понимали проект без восстановления истории по памяти.
