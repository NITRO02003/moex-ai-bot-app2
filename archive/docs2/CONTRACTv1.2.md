# CONTRACTv1.2 - архитектурный и data-контракт проекта

Файл: `docs2/CONTRACTv1.2.md`

Эта версия дополняет `CONTRACTv1.1.md`:
- теперь правила проекта не считаются "внешними";
- контракт прямо опирается на полный свод правил из `PROJECT_RULES_v1.0.md`.

## 0. Что считается обязательным чтением

Перед работой с проектом нужно прочитать:
- `docs2/policies/PROJECT_RULES_v1.0.md`
- `docs2/operations/MIGRATION_CONTEXT_v1.2.md`
- этот контракт

## 1. Главная рамка

- core является главным объектом развития;
- legacy остаётся только как reference;
- sandbox - промежуточный этап к online;
- offline/online рассматриваются как единая исследовательская траектория;
- source of truth для договорённостей теперь строится через docs2.

## 2. Правила как часть контракта

Правила из `PROJECT_RULES_v1.0.md` считаются частью обязательного контекста контракта.
Это включает:
- patch discipline
- directory discipline
- CLI discipline
- versioning discipline
- migration discipline
- LLM discipline

## 3. Что не может быть нарушено

- правила проекта не могут игнорироваться "потому что это не контракт";
- новый чат не может пропускать этап чтения правил;
- нельзя обнулять старую документацию при выпуске новой версии;
- нельзя перестраивать архитектуру молча через патчи.
