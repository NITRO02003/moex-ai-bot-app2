# MIGRATION_CONTEXT_v1.1 - контекст для переезда в новый чат

## 1. Почему эта версия появилась
v1.1 фиксирует новое правило:
- при миграции новый чат обязан сначала знакомиться с правилами и договорённостями между нами;
- документы должны эволюционировать версиями и без потери хронологии.

## 2. Что является текущей рамкой
- core-first development
- legacy = reference only
- sandbox = промежуточный этап к online
- финальная цель = исследовательски честная offline/online система
- docs2 = новый source of truth для миграции и планирования

## 3. Правила, которые новый чат обязан принять сразу
1. Версия файла должна меняться при изменениях.
2. Старое содержание документов не удаляется молча.
3. Исключения только по согласованию.
4. Предложения внешних аналитиков включаются в план, если они приняты, но приоритет зависит от стадии разработки.

## 4. Active code zones
- `app2/cli.py`

## 5. Главные активные риски
- перегруженный `core/backtest.py`
- ambiguity вокруг Dataset A truth
- drift risk config source-of-truth
- leakage risk beyond heuristic validator
- потеря контекста при миграции, если не читать docs2 сначала

## 6. Что делать новому чату первым
1. Прочитать docs2 source-of-truth.
2. Восстановить актуальную стадию проекта.
3. Подтвердить понимание правил между нами.
4. Только после этого предлагать roadmap или патчи.
